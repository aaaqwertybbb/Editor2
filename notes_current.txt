Because your cursor sits nested within the text view structure, adding that class forces a global style invalidation cascade from the cursor node all
the way up through #EDI_text to the layout root. This invalidation drops the engine out of its optimized GPU layer caches and recalculates everything,

<
To keep the text cached perfectly on the GPU, your cursor blinking and focus logic should never touch class names.
Instead, it should mutate composite-only properties directly on the element's style object.

<

To control whether the cursor is actively blinking or frozen solid, use the highly optimized composite property animationPlayState.
Toggling this property stays entirely on the GPU composite track and never forces a document style or paint invalidation.

// Freeze the animation instantly so the cursor remains solid while moving
EDI_cursor_cursorElement.style.animationPlayState = 'paused';

// >

// ...
// When you set style.animationPlayState = 'paused', the browser freezes the animation at whatever exact percentage frame it was on during that millisecond.
// If the animation was on a frame where opacity was 0 (the invisible phase of the blink), setting style.opacity = '1' right next to it gets overridden
// because active CSS keyframes have a higher style cascade priority than standard inline style assignments in many browser rendering states.
//
const animations = EDI_cursor_cursorElement.getAnimations();
if (animations.length > 0) {
    animations[0].currentTime = 0; // Instantly snaps the blink track back to 0%, making it 100% visible
}

// 2. INSIDE YOUR TRAILING EDGE FUNCTION (When movement stops):
function EDI_cursorBlink_trailingEdge(timestamp) {
    const time = timestamp - INTS[fEDI_EDI_cursorBlinkLastTimestamp];
    if (time >= 2500) {
        BYTES[byteEDI_isChecking_cursorBlinkTrailingEdge] = 0;
        
        // Unfreeze the animation track without changing classes!
        EDI_cursor_cursorElement.style.animationPlayState = 'running';
        
        EDI_draw_cursor_debug();
        INTS[fEDI_EDI_cursorBlinkLastTimestamp] = 0;
    }
    else {
        requestAnimationFrame(EDI_cursorBlink_trailingEdge);
    }
}
