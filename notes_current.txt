Step 2:
- Make a directory `this-modifier-extension`
- package.json
- syntaxes/this-modifier.tmLanguage.json
- npm install -g @vscode/vsce
- vsce package
- In vscode open the extensions panel
    - click the three dots in the top right
    - Install from VSIX...
    - The VSIX is in the directory `this-modifier-extension`

package.json:
```json
{
  "name": "this-property-modifier",
  "displayName": "This Property Modifier",
  "version": "1.0.0",
  "engines": {
    "vscode": "^1.0.0"
  },
  "contributes": {
    "grammars": [
      {
        "scopeName": "this.property.injection",
        "path": "./syntaxes/this-modifier.tmLanguage.json",
        "injectTo": ["source.js", "source.ts", "source.tsx"] 
      }
    ]
  }
}
```

syntaxes/this-modifier.tmLanguage.json:
```json
{
  "scopeName": "this.property.injection",
  "injectionSelector": "L:source.js - string - comment, L:source.ts - string - comment, L:source.tsx - string - comment, L:source.python - string - comment, L:source.cs - string - comment",
  "patterns": [
    {
      "match": "\\b(this)(?:\\s{1,3})?(\\.)(?:\\s{1,3})?([a-zA-Z_$][a-zA-Z0-9_$]*)",
```
